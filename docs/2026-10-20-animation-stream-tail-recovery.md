# 大禹治水 HTML 生成失败：流式响应诊断

## 现场证据

- 2026-10-20，新素材接入后的第 3、4 版生成均在进度 12、整片 HTML 生成阶段失败。快照已有 film_expression，尚无 direct_source；没有进入配音或渲染。
- 请求已设置 stream=true，上游返回 HTTP 200 和 text/event-stream。不能将本次故障解释为没有开启流式。
- 使用相同 6 段、约 186 秒的生产请求复现：约 121 秒收到 179 字节（9 块），其中没有任何 choices 内容事件、正文、finish_reason 或 DONE。
- 在保活消息之后，上游直接追加未封装为 data: 行、末尾也没有换行的 JSON error。已识别错误标签 bad_response_status_code。该返回未提供可验证的底层 HTTP 状态；代码按未知上游异常映射到 502，不能把这个映射值当作实际测得的下游 HTTP 502。
- 取消 response_format 的对照请求同样在约 121 秒失败；不将 JSON 输出模式判定为根因。
- 同一配置的小型 HTML 动画流式请求在 63.55 秒成功，收到 4294 个正文字符、finish_reason=stop 和 DONE。因此不能认定接口或密钥整体不可用，也不能仅凭固定耗时断定由哪一层网关超时。
- 增加 reasoning_effort=low 的完整请求对照也在 120.91 秒以相同错误结束，未据此修改正式参数或管理员模型配置。
- 所有诊断只记录事件计数、结束标记、允许的错误标签和耗时，不输出密钥、接口 URL、完整响应错误或教师材料。未调用语音模型。

## 修复及边界

- 流式读取兼容保活后追加的原始 JSON error，消费没有换行的最终 data/DONE 行。
- 保留上游认证、权限、额度、参数、限流及临时故障类别；永久错误不重复请求，临时故障仍只补试一次。
- 输出长度上限和内容限制与真正断流分别报告，不用相同请求因长度不足反复重试。不接受没有终止证据的半截 HTML。
- 这是错误解析和分类修复，不会让上游本身自动恢复。完整项目是否成功必须单独验证，不用小型探针或 HTTP 替身测试冒充。
- 8 个新增回归修复前全部失败，修复后传输专项 20 项通过；完整后端回归 444 项通过、3 项跳过（269.24 秒）。
- 此次未修改大纲、项目数据、素材、配音选项、模型配置或已有预览，也未修改参与 frozen HTML 的编译摘要文件。
