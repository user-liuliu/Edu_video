# 系统配音接入

- 配音选择追加 `system:zh-CN`：系统配音（离线普通话）；保留管理员配置的全部模型音色。
- Docker 后端与 worker 安装 eSpeak NG 普通话、FFmpeg。选择系统音色后直接在服务端离线生成音频，不读取配音密钥、不解析 TTS 模型、不发出 TTS 请求。
- 系统配音输出 48kHz 单声道 PCM，并按各句实际帧数生成句级字幕时间；沿用统一 HTML 校时、预览和同资源 MP4 导出。
- 没有配置模型配音时，离线组件可用即可选系统配音；其他必需模型和大纲审核规则保留。离线组件不存在时不提供不可用选项。
- 系统音色较机械，不等同 Windows Huihui；仅支持简单快慢调整，不提供音色克隆或复杂情感。
- 回归证据：后端 360 项通过（120.79秒）；前端 18 文件、177 项通过；Vue 类型检查与生产构建通过。日志 `.superpowers/sdd/system-speech-*.log`。
