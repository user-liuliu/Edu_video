# 第三阶段：大纲驱动 HTML 动画与 MP4 视频生成

日期：2026-10-18
状态：用户已认可纯代码人物动画样片，批准采用“需求与参考材料 → 大纲 → HTML动画 → MP4”主路线，并要求移除生图模型与图片数量配置。正式生成链尚待实施；本轮先交付配置清理。
基线：第二阶段已交付大纲工作流。新路线替代早先“图片素材＋程序二维动画”候选；不再依赖生图或视频生成模型。

## 1. 已确认的目标和操作流程

- 教师保留三个步骤：输入需求、大纲草稿、视频预览。后台分镜、配音、动画生成与渲染不新增必填页面。
- 用户需求、上传参考材料、启用且已接受的教学偏好共同参与大纲；本次明确要求优先。
- 保留第二阶段素材语义：选择文件仅暂存，保存草稿时上传MinIO；生成大纲先保存，再解析材料。
- 大纲保留目标、逐字稿、画面描述、依据和内容性质。三态审核、先保存再确认规则不变。
- 只有已保存且全部审核通过、教师确认的大纲，才能申请视频生成。
- 理科采用公式、函数、几何、电路等代码绘图动效；文科采用二维场景和人物走动、转身、递物等连贯动作。首版不承诺电影级写实表演或口型同步。
- 所有现有管理/教师侧栏、参数提示和暖棕色界面保留。

## 2. 已批准的制作链路

1. 固定已确认大纲、参考依据、参数、配置和渲染版本快照。
2. 后台将大纲细化为分镜：场景、人物、动作起止、文字、旁白范围、来源对应。分镜不得擅改已审核讲稿和知识点。若必须改变内容，回到大纲保存/复审/确认流程。
3. 按讲稿生成旁白，取得真实音频时长和有效时间戳；随后确定分镜及字幕时间轴。
4. 语言模型生成符合受控场景接口的HTML/SVG/JavaScript动画。整片统一字体、配色、人物、服装、道具、场景与比例。
5. 对代码、资源、画面、内容和字幕进行校验；失败允许有限次数修复，仍失败给出片段及具体原因。
6. 在隔离渲染环境按固定时间步逐帧生成画面，FFmpeg合成片段与整片MP4。网页预览和导出共用场景代码及时间轴。
7. 保存产物到MinIO，提供片段/整片预览、下载、历史版本及失败重试。

## 3. 渲染约束与教学质量

- 场景必须支持按任意时间定位，给定t能恢复完整画面；禁止依赖墙上时钟、用户点击、未经固定的随机数或浏览器后台帧调度决定成片。
- 统一装载资源、字体和尺寸，确认ready之后才逐帧渲染；导出固定帧率。建议首版30 fps。
- 模型代码仅在无业务凭据的隔离任务中执行，限制CPU、内存、时长、文件访问及网络；不得访问应用会话、数据库、内网或任意远程资源。资源由服务端解析并白名单注入。预览也不能在业务页面同源直接执行生成脚本。
- 数学函数、几何、电路及公式使用可校验参数与受控绘图组件。禁止把视觉上像公式当作计算正确。
- 生成前检验结构、语法和场景接口；渲染时检验启动、资源与运行异常；抽取关键帧检查遮挡、越界、字幕安全区、缺字、遗漏动作和内容偏差。自动检查不能保证所有教学事实正确。
- 文科角色保持同片一致；递物包含手部锚点、归属切换及遮挡，转身/走动保持连续。允许二维简化，但不能用整张静态画平移替代动作。
- 原文、数据和图示保留证据来源；历史/文学演绎有性质标识，不表述为真实影像。

## 4. 配音、字幕与输出

- 复用已有配音适配配置及豆包音色，按接口限制分批生成讲稿并保存。
- 以实际音频时长和有效时间戳驱动画面。接口无时间戳时补做句级/字级对齐或明确降低对齐精度，不能伪称精确字幕。
- 分镜按配音窗口编排，不截断讲稿、不任意加速关键动作凑时长。
- 输出H.264/AAC MP4，字幕默认烧录；保留原有横屏、竖屏和方形尺寸选择，目标尺寸在渲染前确定。
- 导出后检查音视频流、时长、尺寸及整片解码；浏览器验证播放/暂停/拖动/下载。音视频播放均支持Range。

## 5. 任务、权限、版本与失败恢复

- 沿用FastAPI/PostgreSQL/Celery/Redis/MinIO，新增视频版本及片段产物清单。
- 管理员统一设置并发额度，每位教师独享。大纲任务与整片视频任务共享该教师计数，一次视频内部多个分镜不重复计数。超限文案“超出最大任务数：已存在x个生成任务”。
- 视频进度持久化：排队、编排、配音、动画、检查、渲染、合成、完成/失败。保持连续加载动效，切页继续任务，回来恢复实际阶段。
- 同一提交幂等；租约、心跳与版本验证防止旧worker覆盖新输出。重试复用已完成片段，主任务直到最终成功/失败才释放配额。
- 按片段保存HTML、音频、字幕、视频及配置指纹。仅旁白/音色变化时重做音频及受时长影响的动画；仅画面变化可复用旁白；顺序变化重新拼接。
- 同项目同教师内复用，所有读取/播放/下载/删除检查项目归属。旧成功成片保持可用；生成新版本失败不会丢失历史视频。
- “我的视频”显示成功成片，“草稿箱”显示未完成工作；旧成片与新工作稿需明确版本。
- 多任务完成依次显示三秒提醒，按完成先后，区分大纲与视频。
- 音视频/HTML上传MinIO后记录清单，数据库发布成功状态；孤立产物可回收。禁止删除现有数据卷。

## 6. 管理员配置清理（本轮实施范围）

- 退役image_gen（画插图）：从用途列表、编辑/测试接口、默认配置、系统可用性门槛及前端类型中移除。旧数据库配置行保留，不读取为有效用途。用户后续明确要求删除旧生图密钥：部署环境已核验其密钥为空，并禁用旧配置、清除旧测试状态；不改动其他模型凭据。
- 移除segment_visuals_min、segment_visuals_max、illustrations_per_minute三个配置。旧JSON读取时忽略，不阻塞使用；下一次保存只写有效参数。
- 移除大纲生成提示词及生成/改写/审核流程中的管理员画面数量范围校验。
- 保留看图识别（上传材料理解、后续画面检查）、大纲/讲稿、审核、Embedding、配音、联网搜索。
- 保留同时生成任务数、失败重试次数、时长允许偏差、长期记忆。
- 现有大纲画面描述结构1—12条的边界保护暂时保留，它是输出大小保护，不是图片数量或后续HTML分镜配额。后续编排不能照此硬凑镜头数。
- 实施建议：首版HTML生成先复用现有大纲语言模型，通过独立提示和受控接口调用；是否独立新增动画代码模型用途后续按实际质量决定，不恢复生图依赖。

## 7. 实施顺序和验收边界

1. 本轮配置清理：回归覆盖旧数据兼容、系统可用性、退役接口、数量约束移除及管理员控件；验证部署页面。
2. 数据与任务：视频版本、片段产物、生成准入、配额、幂等/租约、权限及资源清单。
3. 配音和编排：真实音频、字幕对齐、分镜结构化输出、与已确认讲稿绑定。
4. HTML生成和隔离渲染：受控场景接口、统一视觉、校验修复、固定时间渲染及MP4合成。
5. 现有第三步预览：进度、片段/整片播放、下载、历史、重试及三秒完成通知。
6. 用真实理科、文科各一份大纲验收完整自动链；测试失败恢复、旧成片不丢失、尺寸与字幕、任务额度和资源权限。

已完成效果验证：12秒纯SVG+JavaScript人物样片，网页与MP4共用场景代码，复用已有旁白，本次生图调用为0；它是人工/编码代理直接编写的效果原型，不代表后台自动生成链已交付。MinerU及第二阶段专项质量、备份演练继续按后续清单安排。
