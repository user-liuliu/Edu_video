# 第三阶段：大纲驱动 HTML 动画与 MP4 视频生成

日期：2026-10-18
状态：用户已接受修正版理科/故事样片，正式生成链已实现并通过本轮验收，已部署到本机8080。代码保留在codex/phase3-video-pipeline工作区，尚未提交、推送或合并。
基线：第二阶段已交付大纲工作流。新路线替代早先“图片素材＋程序二维动画”候选；不再依赖生图或视频生成模型。

## 1. 已确认的目标和操作流程

- 教师保留三个步骤：输入需求、大纲草稿、视频预览。后台分镜、配音、动画生成与渲染不新增必填页面。
- 用户需求、上传参考材料、启用且已接受的教学偏好共同参与大纲；本次明确要求优先。
- 保留第二阶段素材语义：选择文件仅暂存，保存草稿时上传MinIO；生成大纲先保存，再解析材料。
- 大纲保留目标、逐字稿、画面描述、依据和内容性质。三态审核、先保存再确认规则不变。
- 只有已保存且全部审核通过、教师确认的大纲，才能申请视频生成。
- 理科采用公式、函数、几何、电路等代码绘图动效；文科采用二维场景和人物走动、转身、递物等连贯动作。首版不承诺电影级写实表演或口型同步。
- 所有现有管理/教师侧栏、参数提示和暖棕色界面保留。

## 2. 已批准的制作链路

1. 固定已确认大纲、参考依据、参数、配置和渲染版本快照。
2. 后台将大纲细化为分镜：场景、人物、动作起止、文字、旁白范围、来源对应。分镜不得擅改已审核讲稿和知识点。若必须改变内容，回到大纲保存/复审/确认流程。
3. 按讲稿生成旁白，取得真实音频时长和有效时间戳；随后确定分镜及字幕时间轴。
4. 语言模型只生成严格Scene JSON数据，可信运行时将其编译成HTML/SVG动画，不执行模型HTML/JavaScript。整片保存角色、比例、配色与风格规范。
5. 对代码、资源、画面、内容和字幕进行校验；失败允许有限次数修复，仍失败给出片段及具体原因。
6. 在隔离渲染环境按固定时间步逐帧生成画面，FFmpeg合成片段与整片MP4。网页预览和导出共用场景代码及时间轴。
7. 保存产物到MinIO，提供片段/整片预览、下载、历史版本及失败重试。

## 3. 渲染约束与教学质量

- 场景必须支持按任意时间定位，给定t能恢复完整画面；禁止依赖墙上时钟、用户点击、未经固定的随机数或浏览器后台帧调度决定成片。
- 统一装载资源、字体和尺寸，确认ready之后才逐帧渲染；导出固定帧率。建议首版30 fps。
- 模型代码仅在无业务凭据的隔离任务中执行，限制CPU、内存、时长、文件访问及网络；不得访问应用会话、数据库、内网或任意远程资源。资源由服务端解析并白名单注入。预览也不能在业务页面同源直接执行生成脚本。
- 数学函数、几何、电路及公式使用可校验参数与受控绘图组件。禁止把视觉上像公式当作计算正确。
- 生成前检验结构、语法和场景接口；渲染时检验启动、资源与运行异常；抽取关键帧检查遮挡、越界、字幕安全区、缺字、遗漏动作和内容偏差。自动检查不能保证所有教学事实正确。
- 文科角色保持同片一致；递物包含手部锚点、归属切换及遮挡，转身/走动保持连续。允许二维简化，但不能用整张静态画平移替代动作。
- 原文、数据和图示保留证据来源；历史/文学演绎有性质标识，不表述为真实影像。

## 4. 配音、字幕与输出

- 复用已有配音适配配置及豆包音色，按接口限制分批生成讲稿并保存。
- 以实际音频时长和有效时间戳驱动画面。接口无时间戳时补做句级/字级对齐或明确降低对齐精度，不能伪称精确字幕。
- 分镜按配音窗口编排，不截断讲稿、不任意加速关键动作凑时长。
- 输出H.264/AAC MP4，字幕默认烧录；保留原有横屏、竖屏和方形尺寸选择，目标尺寸在渲染前确定。
- 导出后检查音视频流、时长、尺寸及整片解码；浏览器验证播放/暂停/拖动/下载。音视频播放均支持Range。

## 5. 任务、权限、版本与失败恢复

- 沿用FastAPI/PostgreSQL/Celery/Redis/MinIO，新增视频版本及片段产物清单。
- 管理员统一设置并发额度，每位教师独享。大纲任务与整片视频任务共享该教师计数，一次视频内部多个分镜不重复计数。超限文案“超出最大任务数：已存在x个生成任务”。
- 视频进度持久化：排队、编排、配音、动画、检查、渲染、合成、完成/失败。保持连续加载动效，切页继续任务，回来恢复实际阶段。
- 同一提交幂等；租约、心跳与版本验证防止旧worker覆盖新输出。重试复用已完成片段，主任务直到最终成功/失败才释放配额。
- 按片段保存HTML、音频、字幕、视频及配置指纹。仅旁白/音色变化时重做音频及受时长影响的动画；仅画面变化可复用旁白；顺序变化重新拼接。
- 同项目同教师内复用，所有读取/播放/下载/删除检查项目归属。旧成功成片保持可用；生成新版本失败不会丢失历史视频。
- “我的视频”显示成功成片，“草稿箱”显示未完成工作；旧成片与新工作稿需明确版本。
- 多任务完成依次显示三秒提醒，按完成先后，区分大纲与视频。
- 音视频/HTML上传MinIO后记录清单，数据库发布成功状态；孤立产物可回收。禁止删除现有数据卷。

## 8. 2026-10-18补充确认：教师交互、片段修改与风格

本节更新与前文冲突时，以本节为准。

### 教师关注内容与成片
- 教师仍使用“输入需求 → 大纲草稿 → 视频预览”三个步骤；大纲中的讲稿与简明画面描述保留。
- 分镜是后台内部编排，不要求教师查看或确认，不新增分镜页面、专业时间轴编辑器或强制分镜审批。
- 生成时展示“正在制作配音”“正在制作动画”“正在合成视频”等易理解的真实状态，保持现有加载动效与跨页恢复。
- 理科目标：公式、函数图像、实验动画与讲解同步，正确表达参数、推导及实验因果。文科目标：以《孔融让梨》等故事，通过简单人物动作与连贯情节表达具体含义；不追求复杂表演。

### 教师定位并修改片段
- 在视频播放位置暂停并点击“修改这一段”，默认定位当前片段，展示对应教学段落与选中范围，允许调整范围后输入自然语言修改要求。
- 首版范围按一个或多个完整片段选择，界面明确显示实际起止时间；不提供任意截取片段中间几秒的精细剪辑（实现默认，非用户新增要求）。这样既能修改指定内容，也避免无意扩大为专业剪辑器。
- 播放器下方提供教学内容段落列表，点击可跳转播放或选择修改；列表使用“孔融选梨”等教学名称，不展示专业分镜参数。
- 每个视频版本保存大纲版本、稳定大纲段落ID、内部动画片段ID及整片开始/结束时间；一个大纲段落可对应多个动画片段，按播放时间定位内部片段。
- 修改请求绑定教师选中的视频版本与片段/范围，不能拿旧版播放时间直接定位新版；新版重新计算所有开始/结束时间。
- 只输入文字时可结合讲稿和动作说明推荐位置；匹配多处必须让教师选定，不能未经选择直接消耗生成任务。
- 仅画面变化时锁定讲稿、知识点与音色，复用仍匹配的配音及其他片段；改变动作长度时必须重新检查音画同步。
- 涉及讲稿、知识点变化时返回大纲编辑、保存、复审与确认，再生成新视频版本；不得通过画面修改接口绕过内容审核。
- 片段修改输出为新视频版本并重新合成；失败不影响旧成片。同一项目不允许相互冲突的活动修改任务；片段修改作为一个视频生成任务占用该教师共享额度，内部片段不另计数（实现选择）。

### 自动选择表达方式（2026-10-19 更新）
- 移除教师表单与管理员页面配置中的“讲解风格”。本次需求中的明确风格要求优先；未明确指定时结合科目、年级及内容自动选择表达方式。

## 9. 正式集成范围与验收边界（2026-10-18）

### 用户补充：通用表现自由（2026-10-18）
- 不按题材、动作名或道具逐个建立白名单。模型可使用通用路径、图形及变换轨道自主组合动作；人物、函数和电路组件以及拿取/交接只是可选快捷能力。
- 审核重点是已确认讲稿的知识、数值、因果、人物关系和故事含义，以及教师明确要求；大纲中装饰、镜头、姿势和预估节奏允许等效表达。不得只因没有使用某个组件、动作不足固定秒数或角色比例有微小变化而拒绝。
- 允许静态停顿、合理进出画面及镜头裁切。主体层裁切到标题与字幕之间，字幕和教学文字保持可读。仍拒绝无效引用、不可执行属性、非有限数值、外部资源和脚本；不通过删除执行校验接受渲染器无法播放的数据。
- 本轮继续沿用受控HTML/SVG渲染，不引入任意模型脚本执行，不改变已确认讲稿或知识审核准入。

- 已实现视频版本/片段表与0005迁移；确认准入、每教师共享大纲/视频配额、幂等、租约保护、旧版本保留、失败重试。
- 真实配音与接口句级时间戳驱动Scene；独立审核模型核对语义，有限修复结构、内容与几何布局。配音/字幕损坏重建时失效下游产物；失败画面修改重试保留原要求。
- 独立非root、无密钥、无外网、只读renderer接收数据；逐帧安全区检查，进程组超时终止与init回收。429有界等待；worker等renderer健康再启动。
- FFmpeg统一解码/重编码拼接，使用实际视频帧时长生成版本专属片段边界，最后边界覆盖完整成片。
- 预览支持真实阶段、播放/下载/教学段落跳转、完整片段画面修改、版本切换与失败恢复；多任务完成按顺序三秒提醒。输出超过目标允许时长偏差时保留完整内容并提示回大纲调整。

- 横/竖/方均按所选尺寸导出，但使用统一1280×720安全舞台等比居中，竖/方会留边，尚无自动重排。讲解风格作用于大纲和动画编排，配音保持既选音色和自然干声，未单独控制语速/韵律参数。
