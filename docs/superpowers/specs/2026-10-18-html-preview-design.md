# HTML动画预览后导出试用方案

## 2026-10-19 已确认路线
- 教师确认已保存且审核通过的大纲后，现有创作模型做一次整片表达整理：口语改写、适度缩略重复、统一画面要求和自然承接；保留片段映射、知识条件、公式数值与故事含义。
- 最终讲稿在动画和配音调用前持久化，失败重试和局部修改复用。教师无需查看中间提示词或操作时间轴。
- 最终讲稿→连续动画初稿及预估句级时间窗→现有语音模型正式配音与真实句级字幕→程序自动校时→带配音完整预览→教师显式导出MP4。
- 校时映射整段动画时钟，动作、镜头、公式、标题共同跟随音频；字幕保留音频播放时间。不宣称供应商未提供的逐字级精度。
- 画面修改复用正式配音；重做配音复用画面设计并重新校时；知识或讲稿正文修改回大纲审核。保留历史版本及未选片段。
- 不更换现有模型，不新增视频AI审核或单独导演编排调用。使用安全Scene数据与固定HTML/SVG运行时。
- 导出不调用模型，校验封存资源哈希。保留旧无clock预览的编译字节及运行器。正式部署需同步更新后端和renderer，本次仅隔离样片验证。

## 已确认需求
- 大纲审核、修改后复审、保存确认规则不变。
- 不更换模型。最终配音和字幕生成一次，HTML预览和MP4使用同一资产。
- 先生成可播放、暂停、拖动和定位片段的HTML动画；教师点击“满意，导出MP4”才开始渲染。
- 视频阶段不调用AI审核模型，也不单独调用模型生成风格/分镜规划。统一风格从参数及整片大纲传入每段生成上下文。
- 画面局部修改复用旁白；讲稿、知识内容改动回大纲审核。
- 保留程序运行、时间轴、音频字幕和导出完整性检查。模型动作不增加白名单。

## 本次实现选择
- 沿用已有场景数据→HTML/SVG编译器与动画运行器，避免更换为任意脚本执行。场景生成即画面制作，不新增编排模型调用。
- snapshot.workflow=html-preview-1 区分新任务；旧任务按原快照兼容执行。新任务完成标记preview_ready，项目仍在草稿箱。
- 预览以音频播放位置为时钟，跨片段定位。iframe沙箱不含allow-same-origin，通过受校验postMessage驱动。
- 导出为独立video_export任务，受现有每教师额度限制；重复提交幂等，固定同一版本、同一HTML/声音/字幕。导出失败保留预览。
- 导出校验存储hash和HTML与当前运行器一致，禁止静默换用另一版运行器。历史MP4继续播放下载。
- 保留已有未提交工作；本次不自动提交、推送或合并。

## 验收
新预览不触发渲染或AI审核；试听和导出音频字节一致；未准备好不能导出；导出权限、幂等、容量、旧版本播放、失败恢复；播放/暂停/拖动/片段切换及退出停止声音；前后端全套测试、生产构建、真实浏览器与短MP4验证。
