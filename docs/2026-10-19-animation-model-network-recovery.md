# 整片 HTML 模型请求失败：分类与有限恢复

日期：2026-10-19

## 故障证据

- 用户截图中“大禹治水”第 1 版失败，提示“整片动画模型连接失败，请稍后重试”。
- 视频任务 `88b272cc-af5f-490b-9b16-e32ef848ab2a` 的进度为 12，执行次数为 1。任务从 13:35:14 UTC 到 13:42:02 UTC，约 6 分 48 秒；该时间是整项任务耗时，并非单次 HTTP 请求耗时。
- 视频快照已有 `film_expression`，没有 `direct_source`，确认失败于整片 HTML 模型请求阶段，尚未进入配音和渲染。大纲生成任务已成功。
- 原实现把 HTTP 网络异常统一转为连接失败，没有记录具体异常类型。旧日志不足以确认本次到底是超时、连接中断还是其他传输异常，不能把推测写成已确认根因。

## 修复

- 在 `backend/app/videos/model_stream.py` 增加瞬态网络恢复：超时、连接错误、限流和上游临时异常，每次请求最多补试 1 次；沿用有上限的退避与 Retry-After 处理。
- 认证、权限和参数等永久错误直接失败，避免无意义重复请求。
- 超时与连接中断使用不同提示；SSE 未完整结束时丢弃残片，以原始请求重试，不误当作 HTML 结构问题要求模型改写。
- 日志仅记录错误类别、HTTP 状态、异常类名、重试次数及耗时，不写入 URL、密钥、教师资料或模型响应正文。
- 未修改 HTML 提示词、运行时协议和摘要参与文件。部署前后运行摘要均为 `e44782fcb1a24f2cf5f314db1ce7fc98e0762d46c14731bdf3d5026fa00d051e`。
